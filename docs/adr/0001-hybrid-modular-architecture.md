# Гибридная модульная архитектура

Используем application use cases и adapters как классы с зависимостями, а правила discovery, naming и sync в core — как чистые функции. Это сохраняет привычную OOP-структуру без множества формальных классов и позволяет тестировать основную логику без Figma и файловой системы; альтернативами были полностью слоистая OOP-архитектура и один функциональный CLI pipeline.
